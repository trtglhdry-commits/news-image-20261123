# The World in One Day — Monday 23 November 2026

One image summing up 23 November 2026's world news: COP31 ending without a deal in Antalya, Ukraine's sea drones sinking the Russian corvette Merkury off Benghazi, and the US–Iran missile, tanker and blockade standoff — plus a world map, regional sections and a day-in-numbers strip.

The entry program (`main.ts`, Node 22, standard library only) copies the pre-rendered 1024×1024 poster `entry.png` to `/output/entry.png`, deterministically and under the 1 MiB limit.
